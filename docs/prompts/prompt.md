## 3. Генерация класса `Book`

**Инструмент:** Claude (Anthropic)  
**Дата:** 22.10.2026

**Промпт:** файл с условием лабораторной (`lab1.md`) был передан ИИ целиком, включая промпт из раздела «Применение ИИ-инструмента»:

```
Ты — опытный Java-разработчик. Создай класс Book на Java 17 со следующими
требованиями:
- Поля: id (long), title (String), author (String), year (int). Все private.
- Для каждого поля — getter и setter.
- В setter'ах реализуй валидацию: title и author не могут быть null или пустыми,
  year должен быть от 0 до текущего года. При нарушении — IllegalArgumentException.
- Метод getDescription(), возвращающий строку вида:
  "Название" — Автор (год)
- Переопредели toString() для вывода через System.out.println.
Код должен быть чистым, с Javadoc-комментариями.
```

**Ответ ИИ:**

```java
import java.time.Year;

/**
 * Книга. Хранит данные о книге и защищает их от некорректных значений.
 */
public class Book {

    private long id;
    private String title;
    private String author;
    private int year;

    /** Пустой конструктор: поля потом задаются через setter'ы. */
    public Book() {
    }

    /** Конструктор со всеми полями. Значения проходят через setter'ы, поэтому валидация работает и здесь. */
    public Book(long id, String title, String author, int year) {
        setId(id);
        setTitle(title);
        setAuthor(author);
        setYear(year);
    }

    /** @return уникальный идентификатор книги */
    public long getId() {
        return id;
    }

    /** @param id уникальный идентификатор книги */
    public void setId(long id) {
        this.id = id;
    }

    /** @return название книги */
    public String getTitle() {
        return title;
    }

    /**
     * @param title название книги
     * @throws IllegalArgumentException если название null или пустое
     */
    public void setTitle(String title) {
        if (title == null || title.isBlank()) {
            throw new IllegalArgumentException("Название не может быть пустым");
        }
        this.title = title;
    }

    /** @return автор книги */
    public String getAuthor() {
        return author;
    }

    /**
     * @param author автор книги
     * @throws IllegalArgumentException если автор null или пустой
     */
    public void setAuthor(String author) {
        if (author == null || author.isBlank()) {
            throw new IllegalArgumentException("Автор не может быть пустым");
        }
        this.author = author;
    }

    /** @return год издания */
    public int getYear() {
        return year;
    }

    /**
     * @param year год издания, от 0 до текущего года
     * @throws IllegalArgumentException если год вне допустимого диапазона
     */
    public void setYear(int year) {
        if (year < 0 || year > Year.now().getValue()) {
            throw new IllegalArgumentException("Некорректный год: " + year);
        }
        this.year = year;
    }

    /** @return строка вида: "Война и мир" — Толстой Л.Н. (1869) */
    public String getDescription() {
        return "\"" + title + "\" — " + author + " (" + year + ")";
    }

    /** Его вызывает System.out.println(book). */
    @Override
    public String toString() {
        return getDescription();
    }
}
```

## 4. Анализ результата ИИ (чеклист из задания)

| Проверка | Результат | Комментарий |
|----------|-----------|-------------|
| Валидация `title` и `author`: `null` проверяется раньше `isBlank()` | Да | Условие `title == null \|\| title.isBlank()`: при `null` вычисление останавливается до вызова `isBlank()`, поэтому `NullPointerException` не возникает |
| Валидация `year`: диапазон от 0 до текущего года | Да | Условие `year < 0 \|\| year > Year.now().getValue()`, текущий год берётся из системы, а не зашит в код |
| Использование `this` в setter'ах | Да | `this.title = title;` и аналогично для остальных полей: поле отличается от параметра с тем же именем |
| Формат `getDescription()`: `"Название" — Автор (год)` | Да | Результат: `"Война и мир" — Толстой Л.Н. (1869)`, кавычки экранированы как `\"` |
| Переопределён `toString()` | Да | Возвращает `getDescription()`, поэтому работает `System.out.println(book)` |
| Javadoc-комментарии | Да в ответе ИИ, нет в итоговом файле | В ответе ИИ Javadoc есть у класса, конструкторов и методов, у setter'ов указано `@throws IllegalArgumentException`. В итоговом `Book.java` Javadoc-комментарии отсутствуют |

**Что доработал вручную:** логика класса `Book` осталась без изменений; в итоговой версии файла нет Javadoc-комментариев, а комментарии в `Main` сокращены.
